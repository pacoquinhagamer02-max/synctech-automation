📱 Ativar WhatsApp Bot 24/7 (Z-API)
3 passos — sem custo de plataforma extra além da Z-API
1
Crie conta gratuita na Z-API
Acesse z-api.io → Cadastre-se → Crie uma instância → Escaneie o QR Code com o WhatsApp do negócio.
2
Copie Instance ID e Token
No painel Z-API: Instâncias → clique na instância → API → copie o Instance ID e o Client Token.
3
Configure no Make.com
Cenário: Webhooks (recebe msg) → Filtro de palavra-chave → Z-API (envia resposta). Cole Instance ID e Token na conexão.
Abrir Z-API → Abrir Make.com →
